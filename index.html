Firebase-yhdistys — tehdään kerran, toimii ikuisesti
Yhdistä pilvitietokantaan
Firebase Firestore tallentaa tilat ja tekstit pilveen. Sama data näkyy kaikilla laitteilla heti kun refreshaat sivun. Täysin ilmainen tälle käyttömäärälle.
1
Luo Firebase-projekti
Mene console.firebase.google.com → "Add project" → anna projektin nimi (esim. "pmj-julkaisut") → jatka oletuksilla → Create project.
2
Lisää web-sovellus & kopioi konfiguraatio
Projektin etusivulla klikkaa </> (Web) → anna nimeksi "pmj" → Register app. Kopioi firebaseConfig-lohko ja liitä se alla olevaan kenttään.
3
Aktivoi Firestore
Vasemmassa valikossa: Build → Firestore Database → Create database → Start in test mode → Next → Enable.
4
Aseta turvallisuussäännöt
Firestore → Rules-välilehti → korvaa kaikki tällä ja paina Publish:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }
